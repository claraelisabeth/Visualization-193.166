Overview

This is the code documentation for the Edge Path Bundling project, which implements the edge bundling algorithm described in "Edge-Path Bundling: A Less Ambiguous Edge Bundling Approach" by Wallinger et al. The implementation includes a complete Python codebase with interactive visualization capabilities.

The project is organized into several main components: core bundling algorithm implementation, data loading modules for different dataset types, dashboard application for interactive exploration, and visualization rendering with Plotly. The data folder contains three datasets (air traffic, brain connectivity, migration flows), while the documentation folder includes this code documentation along with project documentation and demo materials.

bundling.py

The core implementation of the Edge-Path Bundling algorithm following Algorithm 1 from the paper by Wallinger et al. This module provides the main bundling functionality that processes graphs to create bundled edge paths while maintaining a maximum distortion threshold.

Key Functions

  • bundle_edges(graph, k, d) - Main algorithm implementation that processes edges in weight order and finds shortest paths for bundling
  • create_graph(nodes, edges, distance_type) - Creates a NetworkX DiGraph from node/edge data with spatial attributes
  • haversine_distance(lat1, lon1, lat2, lon2) - Calculates great circle distance for geographic coordinates
  • euclidean_distance(x1, y1, x2, y2, z1, z2) - Calculates Euclidean distance in 2D or 3D space
  • dijkstra_with_skip(graph, source, target) - Modified Dijkstra's algorithm that excludes locked edges

Algorithm Parameters

  • k (distortion threshold) - Maximum allowed detour ratio (path length / direct distance)
  • d (edge weight factor) - Exponent for edge length weighting (weight = length^d)

The algorithm sorts edges by weight (heaviest first), then for each edge attempts to find a shortest path while excluding previously bundled edges. If the path's detour ratio is within the threshold k, the path is accepted and its edges are locked. Performance optimizations include early stopping and edge limits for large graphs.

data_loader

Collection of specialized data loading modules that handle different dataset formats and coordinate systems. Each loader creates NetworkX graphs with appropriate distance metrics and spatial attributes for the bundling algorithm.

air_traffic.py

Loads OpenFlights airport and route data, handling CSV parsing for airport coordinates and route connections. Uses haversine distance for geographic calculations. Filters invalid entries and creates directed graph with airport metadata including IATA codes, cities, and coordinates.

brain_connectivity.py

Processes GraphML files from the Human Connectome Project containing 3D brain region coordinates and structural connections. Handles MNI coordinate system conversion and creates 3D visualizations using Euclidean distance. Supports filtering by connection strength thresholds.

migration.py

Parses US Census Bureau county-to-county migration flow data. Converts FIPS county codes to geographic coordinates and filters by minimum flow thresholds. Uses haversine distance for geographic calculations and handles coordinate lookup for US counties.

app.py

Interactive Dash web application that provides a user interface for exploring edge path bundling on different datasets. Features parameter controls, real-time visualization updates, and performance optimizations including caching and progressive loading.

Key Features

  • Parameter Controls - Sliders for bundling factor (k), edge weight factor (d), and smoothing level
  • Dataset Selection - Dropdown for switching between brain, air traffic, and migration datasets
  • Visualization Options - Toggle between highlighted and normal coloring for bundled edges
  • Performance Optimization - Caching system for datasets and bundling results
  • Responsive Design - Academic-styled interface with sidebar controls and main visualization area

Callback Architecture

Uses Dash callbacks for reactive updates: parameter displays update immediately, dataset changes reset controls, bundling recalculation occurs for algorithm parameters, and fast updates for visualization-only changes. Implements smart caching to avoid redundant computations.

Performance Constants

  • Major airports limited to 50 for demonstration
  • Migration data filtered to top 100 counties
  • Minimum flow threshold of 3,000 for migration data
  • Fixed curve sampling at 80 points for smooth rendering

plotly_renderer.py

Comprehensive visualization module that renders bundled graphs using Plotly with support for 2D geographic maps, 3D brain visualizations, and smooth B�zier curve generation. Automatically detects data types and applies appropriate rendering strategies.

Visualization Types

  • Geographic Maps - Uses Plotly's Scattergeo for air traffic and migration data with automatic US/world map detection
  • 3D Brain Visualization - Interactive 3D plots for brain connectivity data with rotation and zoom controls
  • Standard Network Plots - 2D scatter plots for general network data with optional geographic overlays

Curve Generation

Implements smooth B�zier curve generation using recursive subdivision and De Casteljau's algorithm. Supports configurable smoothing levels (adding control points) and sampling resolution. Works in both 2D and 3D coordinate systems for consistent curve appearance.

Performance Features

  • Automatic edge limiting for dense networks (500-1000 edges)
  • Color scheme optimization for different visualization contexts
  • Hover information with path details and distortion ratios
  • Responsive layout configuration for different screen sizes

The module uses explicit dataset type detection for faster rendering, falling back to automatic detection for backward compatibility. Geographic data detection uses coordinate range validation and spread analysis.
